# Vanguard Realty — Платформа автоматизации агентства недвижимости с ИИ и Telegram

Полнофункциональный сайт для автоматизации агентства недвижимости **Vanguard Realty** со встроенным ИИ-помощником (`gemini-3.5-flash-lite`), квиз-подборщиком, системой записи клиентов на просмотр конкретной квартиры по дате, двусторонней интеграцией с Telegram-ботом и Админ-панелью.

## Основные возможности

1. **Две темы оформления (Dark & Light)**:
   - Мгновенное переключение между премиальной темной темой (*Luxury Onyx & Gold*) и светлой темой (*Architectural Ivory*).
2. **Параллакс и плавные анимации при скролле**:
   - Инерционный плавный скролл на базе `Lenis` и многослойный параллакс-эффект (`Framer Motion` / `IntersectionObserver`).
3. **Умный ИИ-помощник (`gemini-3.5-flash-lite`) и ИИ-Квиз**:
   - Отвечает на вопросы по услугам агентства, подбирает квартиры из базы по бюджету, количеству комнат и району и мягко переводит клиента к заявке на просмотр.
4. **Запись клиентов на конкретный день просмотра**:
   - Клиент выбирает объект недвижимости, указывает удобную дату и время просмотра и свои контакты.
5. **Двусторонняя связка с Telegram**:
   - Все заявки с сайта автоматически дублируются в рабочую Telegram-группу (`TELEGRAM_GROUP_CHAT_ID`).
   - Telegram-бот (`scripts/telegram-bot.mjs` и `/api/telegram`) записывает клиентов и передает заявки напрямую в Админ-панель сайта.
6. **Админ-панель (`/admin`)**:
   - Добавление новых объектов недвижимости (название, район, адрес, стоимость, комнаты, площадь, фото и описание).
   - Управление всеми заявками клиентов и их статусами.

## Быстрый запуск

### Вариант 1: Next.js (Fullstack TypeScript)
```bash
npm install
npm run dev
# В отдельном терминале для запуска Telegram-бота (Long Polling):
npm run bot
```
Откройте `http://localhost:3000` (Админ-панель: `http://localhost:3000/admin`, пароль по умолчанию: `vanguard2026`).

### Вариант 2: Автономный запуск без Node.js
Если Node.js еще не установлен, вы можете сразу открыть [index.html](file:///c:/Users/User/Desktop/AI/estate-agency/index.html) или запустить легковесный сервер:
```bash
python server.py
```

## Настройка ключей (`.env.local`)
Укажите ваши ключи в файле `.env.local`:
```env
GEMINI_API_KEY=ваш_ключ_gemini
GEMINI_MODEL=gemini-3.5-flash-lite
TELEGRAM_BOT_TOKEN=токен_вашего_тг_бота
TELEGRAM_GROUP_CHAT_ID=id_вашей_рабочей_группы
ADMIN_PASSWORD=vanguard2026
```
